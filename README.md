# Catch Panda

A desktop app to detect AI-generated content on your screen.

## Setup

1. Clone this repo
2. `npm install`
3. Add your API keys in the app (Info > Hive Key / Copyleaks Key)
4. `npm start` or `npx electron .`

## Requirements

- Hive API key (for image detection)
- Copyleaks API key + email (for text detection)
